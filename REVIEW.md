# REVIEW.md

| # | Where (function / line) | What is wrong | How you'd notice it (test, input, or symptom) | How you fixed it |
|---|---|---|---|---|
| 1 | `GET /health` | Returns `{"status":"ok"}` without pinging Mongo; never 503. | Stop Mongo → still 200, runner thinks ready. | `admin.command("ping")`, 503 on failure. |
| 2 | `compute_late_minutes` | Uses naive `replace(hour…)` on punch instant, no IST conversion; `minutes > 10` instead of `diff_seconds > 600`; no truncation. | Punch `09:40:01 IST` or any TZ-aware input gives wrong late; `09:40:00.900` should be 0 but micros leak. | Truncate to seconds, convert to IST, compare to `shift_start` on attendance date, `diff<=600→0` else `floor(diff/60)`. |
| 3 | `compute_work_hours` | Python `round()` = banker's rounding, not half-up. | Duration yielding `x.xx5` (e.g. 2.675) rounds to even instead of up. | `Decimal(str(secs/3600)).quantize(0.01, ROUND_HALF_UP)`. |
| 4 | `compute_overtime` | `datetime.fromisoformat(date).replace(tzinfo=IST)` builds wrong wall time; ignores overnight (end next day); no 30-min minimum. | `18:35` with `18:30` end returns 5 not 0; overnight `06:40` next day returns ~24h overtime. | IST `shift_end` on correct day (next day if overnight), `floor` minutes, `<30→0`. |
| 5 | `EmployeeIn` | No patterns: `emp_code`, `email`, `HH:MM`, `joined_on`, `shift_start != shift_end` unchecked. | `POST {"email":"bad","shift_start":"09:30","shift_end":"09:30"}` → 201 not 422. | Pydantic `pattern` + `field_validator` + explicit same-shift 422. |
| 6 | `POST /employees` | Check-then-insert race; `datetime.now()` naive; returns raw `datetime`, leaks internal shape. | 2 parallel duplicate `emp_code` → two 201; `created_at` not epoch ms. | Unique index on `emp_code`, catch `DuplicateKeyError→409`, UTC-truncated `created_at`, serialize to ms, strip `_id`. |
| 7 | `GET /employees` | `skip = page*page_size` (off-by-one); `total` counts whole collection; no sort; no page validation; datetimes raw. | `page=1` skips first 20; `?department=X` total wrong; order random. | `skip=(page-1)*size`, filtered `count_documents`, `sort emp_code asc`, R10 validation, ms serialization. |
| 8 | `POST /attendance/punch-in` | `emp=None` → `emp["shift_start"]` 500 not 404; `ts.date()` UTC not IST R1; no overnight; any `status` accepted; check-then-insert race; returns `id` + raw datetimes; no truncation/ms validation. | Unknown emp → 500; overnight `02:00 IST` date wrong; `status=ABSENT` → 201; parallel same-date → two 201; response has `id`. | 404 guard, IST R1 date w/ overnight, presence-only 422, `StrictInt` epoch range, truncate, unique `(emp_code,date)` insert→409, contract shape. |
| 9 | `GET /attendance` | Loads entire collection, Python `sort` only by `date`, slices in memory; `total=len(docs)` after load; leaks `_id` as `id`; no `date_from>date_to`/status validation. | 100k docs OOM/slow; tie order `emp_code` wrong; `id` field fails contract. | DB `find+sort(date desc,emp_code asc)+skip/limit`, filtered `count_documents`, strip `_id`, ms conversion, 422 checks. Uses `idx_att_date_emp`. |
| 10 | `punched_at` typing | `Optional[int]` coerces floats/strings, accepts seconds-like values. | `{"punched_at":1750000000}` or `123.5` → 201 not 422. | `StrictInt` with `ge=1e11, le=4102444800000`; bool/float/str → 422. |
| 11 | Mongo client / time | `MongoClient(...)` not `tz_aware`; naive vs aware mixed silently. | Stored BSON dates come back naive, IST math shifts by 5:30 depending on host. | `tz_aware=True` + `ensure_utc()` at every boundary. |
| 12 | Indexes | None created. | `explain` shows COLLSCAN; list/analytics slow on 100k. | `ensure_indexes()` at startup (unique emp_code, unique emp_date, date/emp, punch_in, dept/joined). |

Also examined and **not** defects: `PunchInIn.status` default `PRESENT` (matches contract); `attendance` `date_from/date_to` inclusive `$gte/$lte` semantics; `history: []` init on punch-in (correct — punch never writes history).
